Changelog

Changes, fixes, and development milestones for Kossman Stats.

0.1.0 First release

Initial Fabric 26.2 release

First public release of the modern GokiStats continuation.

Added

  • Modernized stat progression system.
  • Persistent per-player stat progression.
  • XP-based upgrades and stat level caps.
  • Individual stat downgrade with 70% XP refund.
  • Stat loss on death with weighted penalties.
  • Server-side gameplay configuration.
  • Client/server stat synchronization.
  • Gathering, combat, defense, movement, survival, and loot-related stats.
  • Modernized Kossman Stats interface.
  • Custom stat icons with inactive, active, and maximum-level states.

Changed

  • Rebalanced legacy progression and stat formulas for modern Minecraft gameplay.
  • Reworked legacy Forge systems into a modern Fabric architecture.
  • Updated loot mechanics to use modern data-driven definitions where appropriate.

Fixed

  • Player state synchronization across death and respawn.
  • XP affordability calculations around vanilla XP bar thresholds.
  • Dedicated-server balance synchronization.
  • Player-placed block farming for bonus loot-related stats.
